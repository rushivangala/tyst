**Password manager suggestions in the keyboard.**

### Fixed
- NordPass (and other password managers) can now show login suggestions above the keys. Tyst's request now uses the chip style and presentation slots password managers expect. Pills show as soon as each one is ready, and they're clipped to the strip.

### New
- **Settings › Passwords & codes › Autofill check** shows what the keyboard last heard from Android's autofill: asked, the number of suggestions sent, the number shown, or an error. If suggestions don't appear, it shows where they stopped.

### Install
Download `tyst-v1.0.1.apk` below and open it. It installs over v1.0.0 and keeps your settings and what Tyst has learned.
