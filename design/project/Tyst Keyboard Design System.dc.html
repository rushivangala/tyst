Color tokens

Neutrals carry a faint green-grey tint so the plate reads as calm rather than clinical. Depth comes from a 1dp bottom edge on keys and tone steps between plate, key and special key. No gradients. Contrast is measured against the surface each token sits on.

Accent system

One accent role, four tokens: accent, on-accent, accent-container and on-accent-container. Nothing else on the keyboard is colored. The source of the accent is one of three: wallpaper, a fixed palette, or the time of day.

Dynamic color (wallpaper)

  1. Source is the system dynamic palette (system_accent1_*). Tyst re-reads it on every configuration change, so a new wallpaper applies on the next keyboard show.
  2. Mapping: accent = tone 40 light / 80 dark. On-accent = 100 / 20. Container = 90 / 30. On-container = 10 / 90.
  3. Calm cap: rendered chroma is clamped to 0.09 OKLCH. A saturated wallpaper gives a muted version of its hue.
  4. Contrast guard: accent against on-accent and against kb.key must reach 4.5:1. If not, step the tone 5 darker (light) or lighter (dark), up to three steps. If it still fails, fall back to Hav.
  5. Neutrals stay Tyst neutrals. Plate and keys pick up the wallpaper hue at chroma 0.012 or less, so keys never look colored.
  6. Wallpaper color is the default on first run. Choosing a fixed palette or time-of-day rotation turns it off.

  1. Opt-in: Settings › Accent › Change with the time of day. Off by default.
  2. Uses the local clock only. Tyst has no location or network permission, so windows are fixed rather than tied to sunrise.
  3. Never changes while the keyboard is visible. A new window applies on the next show, using the accent transition (600ms).
  4. Light or dark still follows the system. Each window uses its palette's light or dark values.
  5. Picking a palette by hand, or turning on wallpaper color, turns rotation off.
  6. With Remove animations on, the accent switches instantly.

Typography

Google Sans Flex, the Pixel system face, for everything. Sizes are in sp and scale with the system font size up to 130%; above that, keys hold at 130% and the strip truncates with an ellipsis.

Motion
