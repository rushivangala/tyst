Product spec · v0.1 · 20 Oct 2026

Tyst: an on-device keyboard that writes like you

Spec for design handoff. Android 17, optimised for Pixel 10 Pro. "Tyst" (Swedish for quiet) is a working name.

Assumptions

  • MVP ships on the Pixel 10 series only (Tensor G5, 12–16 GB RAM). Other devices come later behind a capability check.
  • Distribution through Google Play. Model files ship as Play Asset Delivery packs, which Play downloads, so the app itself never needs network access.
  • The UI is in English. Swedish is a recognition layer inside English typing. It is not a second keyboard language.
  • Gemini Nano is not reliably callable from a keyboard (see §7). The plan does not depend on it.
  • The user sets NordPass, or another password manager, as their Android autofill service.
  • Free MVP. Monetisation is out of scope.
  • Competitor notes describe public behaviour as of October 2026 and should be checked before external use.

01Positioning and USP

Positioning: For Pixel owners who write a lot and care about privacy, Tyst is an AI keyboard that learns their own voice and runs entirely on the phone, with no internet permission.

USP: The keyboard that writes like you and never goes online.

02Personas

P1 · Elin, 34

Swedish UX lead at a London company. Writes in English all day, about people and places at home.

  1. Autocorrect breaks Swedish words: "Västerås" becomes "Vasteras", "fika" becomes "fiancé".
  2. Switching languages mid-sentence is slow and upsets English predictions.
  3. Getting to å/ä/ö takes a long-press or a layout switch.

P2 · Marcus, 41

Security engineer. His employer's policy bans cloud keyboards and AI writing tools.

  1. He can't use AI writing help because every option sends text to a server.
  2. He can't confirm what a keyboard stores or uploads.
  3. He keeps retyping booking references, addresses and account numbers.

P3 · Priya, 29

Operations manager. Moves between Slack, Gmail and WhatsApp all day.

  1. AI rewrites sound generic and not like her, so she rewrites them again.
  2. She has to switch tone by hand between her boss, clients and family.
  3. Logins and 2FA codes mean leaving the app, copying and coming back.

Why switch

  • Proof: the app holds no internet permission, which anyone can check in system Settings. The other four can only make policy promises.
  • Voice: rewrites learn from the user's own accepted text, per app. The others offer generic tone presets.
  • Swedish inside English: Swedish is recognised word by word with a guard against "correcting" it. No language switching.
  • Recall: private memory brings back booking numbers and addresses with no cloud account.

06Core flows

6.1 First-time setup

  1. The user installs from Play. The base prediction model installs with the app. Play queues the writing-model pack (about 1 GB) as an on-demand download.
  2. Welcome screen: the promise, plus the permission card (Microphone: ask · Internet: not requested).
  3. Enable: a deep link opens system input settings. The app sees the keyboard is enabled and moves on by itself.
  4. Default: the system keyboard picker opens and the selection is confirmed.
  5. Swedish words: on by default if the device region or a second locale is Swedish. Shows "fika in Västerås" left uncorrected.
  6. Passwords & codes: shows the current autofill service ("NordPass ✓"), or links to autofill settings.
  7. Learning: style learning is pre-selected on. Private memory is off until the user turns it on.
  8. Look & feel: system mode and dynamic colour are pre-selected.
  9. Try it: a guided sentence shows prediction, the Swedish guard, and Rewrite once the model is ready.
  10. Done. Until the pack lands, AI keys show "Preparing writing model · 62%".

6.2 Typing with predictions

  1. A field gets focus. The keyboard reads the field's metadata: app, input type, hints, and any no-learning flag. Password and no-learning fields switch to incognito: no learning, a visible indicator, and memory hidden.
  2. The strip shows three predictions, with the most likely one in the centre, ranked by the personal model.
  3. Typing "Väst" offers "Västerås". Typing "Vasteras" offers "Västerås" as a suggestion but doesn't swap it in automatically.
  4. Space commits the word. Autocorrect only fires when confidence is high and the word is not in the English, Swedish or personal lexicon.
  5. Backspace straight after an autocorrect restores the original word. After two restores, the word is learned.
  6. Long-press a/o for å ä / ö, or turn on the å ä ö keys in Settings.

6.3 Rewriting "in my style"

  1. Type a draft of 3 or more words, or select text. Tap Rewrite in the strip.
  2. The Rewrite sheet opens above the keys, preset to that app's default (e.g. Slack: My style · Shorter).
  3. Tone chips: My style, Warmer, Formal, Shorter, Longer. The first words appear in under 0.7 s and the rest streams in.
  4. Swipe between up to 3 variants. Changed words can be highlighted.
  5. Replace, Insert below or Copy. An Undo snackbar stays for 5 s.
  6. Swedish words and proper nouns stay exactly as typed. Accepted and rejected variants tune the style model on the device.

6.4 Using private memory

  1. The user opts in (during setup or in Settings › Memory).
  2. While typing in normal fields, the keyboard picks out addresses, booking references, names and emails. They go into a "New" queue in What I learned. Nothing is captured in incognito or excluded apps.
  3. When a field hint matches (e.g. a postal address field) or the text does ("my booking ref is"), the strip shows a memory chip with a lock icon: "ABX4KT · SAS".
  4. Tap inserts it. Long-press shows the source app and date, with Forget and Pin.
  5. The Memory key opens a searchable panel. A biometric prompt appears if the lock is on.
  6. Items expire after 90 days by default unless pinned.

6.5 Logging in with a NordPass suggestion

  1. The user taps the username field in an app's login screen.
  2. The keyboard asks Android for inline autofill suggestions. NordPass replies with account pills.
  3. The strip shows the system-drawn pill(s) on the left, and predictions shrink. The keyboard can't read what the pills contain.
  4. Tap a pill. NordPass may ask for a biometric check, then fills the username and password.
  5. Focus moves to the password field, which is incognito.
  6. No pill? The strip shows an "Open NordPass" key as a fallback.

6.6 Entering a verification code

  1. The code arrives by SMS or email. The user copies it, or the autofill service offers it.
  2. The user focuses the code field. It is recognised by a one-time-code hint or a numeric field with a short max length.
  3. The strip shows a chip, "Code 482 913 · Clipboard · 40 s ago", but only for clips under 3 minutes old that look like a 4–8 digit code. Autofill-provided codes show as a pill in the same spot.
  4. Tap fills the field. Split single-digit boxes are filled by sending one key event per digit.
  5. The chip disappears after use or after 3 minutes. The code is never kept in clipboard history or memory. Optionally, the clipboard is cleared after pasting.

6.7 Changing theme and accent

  1. Open Settings › Appearance, or long-press the comma key › Theme.
  2. Mode: Light / Dark / System segmented button.
  3. Accent: Dynamic (from the wallpaper) or one of 8 curated accents. Multi-select is on when rotation is on.
  4. Auto-rotate: Off / Daily / Weekly, cycling through the selected accents.
  5. A live keyboard preview is pinned at the bottom. Options: key borders, height, number row.
  6. Changes apply at once. No save step.

6.8 Reviewing what the keyboard learned

  1. Open Settings › What I learned. An optional weekly local notification also links here: "12 new words, 3 memory items".
  2. Words tab: newly learned words with the apps they came from. Swedish words carry an SV badge. Remove or block each one.
  3. Style tab: notes in plain language with examples ("Short sentences in Slack", "You sign off 'Hej hej' with family"). Each can be toggled per app.
  4. Memory tab: each item shows type, source app and date. Edit, pin or delete.
  5. Bulk actions: Pause learning; Delete everything (confirmation, then the encryption key is destroyed).
  6. Export: an encrypted file through the system file picker or share sheet.
